## Phase 1: Design

Use three existing stages to tell a concise conceptual story:

1. Observe: field observations and notes as context for useful safety records.
2. Understand: AI-assisted organization and review, with uncertainty and human verification.
3. Decide: people choose actions; intended follow-up supports responsibility and progress.

Keep the primary home/about message practical rather than solely focused on hazard detection.
State that the product is in development on all four product-facing pages. Keep contextual
qualifiers near capability descriptions so direct navigation does not depend on a disclaimer
elsewhere. Follow-up remains a described intent, not a simulated action-management interface.

[data-model.md](data-model.md) describes content-only concepts without adding persisted entities.
[contracts/public-content.md](contracts/public-content.md) defines wording boundaries and existing
UI invariants. [quickstart.md](quickstart.md) maps implementation checks to the specification.
